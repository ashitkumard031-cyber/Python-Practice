# 🐍 Python Practice Programs & Core Logic Building

Welcome to my Python programming repository! This project documents my hands-on coding journey as I build and refine my core programming fundamentals, algorithmic thinking, and problem-solving skills in Python. 

Every script in this repository is written from scratch with a focus on clean syntax, proper input handling, and clear logical flow.

## 🎯 Objectives of This Repository
* Build a strong foundation in Python syntax, data types, and control structures.
* Practice breaking down everyday problems into modular, step-by-step code.

## 📂 Programs Included

| File Name | Program Title | Key Concepts Used | Description |
| :--- | :--- | :--- | :--- |
| `hello.py` | **Hello World** | `print()`, Basic Syntax | Introductory script demonstrating standard output formatting in Python. |
| `even_odd.py` | **Even or Odd Checker** | `if-else`, Modulo (`%`), Type Casting | Takes integer input from the user and determines whether it is even or odd. |

## 🚀 Getting Started & How to Run

### Prerequisites
Make sure you have **Python 3.x** installed on your system. You can verify your installation by running:
```bash
python3 --version
```

### Installation & Execution
1. **Clone the repository to your local machine:**
   ```bash
   git clone [https://github.com/ashitkumard031-cyber/Python-practice-.git](https://github.com/ashitkumard031-cyber/Python-practice-.git)
   ```
2. **Navigate into the project folder:**
   ```bash
   cd Python-practice-
   ```
3. **Run any script using Python 3:**
   ```bash
   python3 calculator.py
   ```
   *(Replace `calculator.py` with any other filename from the list above.)*
